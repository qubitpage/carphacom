# Carphacom Vultr Marketplace Gallery Upload Instructions

Use these images for **Vultr Marketplace → Edit App → Application Gallery → Upload Graphic**.

All files are polished PNG screenshots at the Vultr suggested size:

```text
800 x 500 px
```

## Source of screenshots

These gallery images were captured from a fresh verification instance booted from the final Carphacom Developer Edition Vultr Marketplace image.

The screenshots show only public Carphacom storefront routes from that final image.

## Do not upload

Do **not** upload:

- admin login screenshots
- Vultr cockpit/control-panel screenshots
- infrastructure dashboards
- warehouse panels
- terminal screenshots
- route diagrams
- screenshots from `demo.qubitpage.com`
- screenshots from unrelated example sites
