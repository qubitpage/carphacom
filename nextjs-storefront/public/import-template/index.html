📋 Câmpuri OBLIGATORII REQUIRED

Fără aceste câmpuri, produsul nu poate fi importat.

Coloană Tip Descriere Exemplu
sku Text Cod unic produs (SKU) - identificator unic FOMCO-CB-450
title Text Numele complet al produsului Stație Radio CB Fomco 450
price Număr Preț cu TVA în BANI (nu lei!) - 459 lei = 45900 45900
stock Număr Stoc disponibil (număr întreg) 25

⭐ Câmpuri RECOMANDATE RECOMMENDED

Pentru un import complet și afișare optimă pe site.

Coloană Tip Descriere Exemplu
description Text/HTML Descrierea produsului (poate conține HTML) <p>Stație radio CB...</p>
category Text Categoria produsului Stații Radio CB
brand Text Producător/Marca Fomco
ean Text Cod de bare EAN-13 5949012345678
weight Număr Greutate în grame 450
thumbnail URL URL imagine principală (HTTPS) https://site.ro/img/prod.jpg
images URL(s) URL-uri imagini adiționale (separate prin ;) url1.jpg;url2.jpg;url3.jpg

🔧 Câmpuri SPECIFICAȚII SPECS

Specificații tehnice care vor apărea în pagina produsului. Prefixul spec_ este obligatoriu.

Coloană Descriere Exemplu
spec_putere Putere de emisie 4W
spec_canale Număr canale 40
spec_frecventa Bandă de frecvență 26.965-27.405 MHz
spec_alimentare Tensiune alimentare 12-24V DC
spec_impedanta Impedanță 50 Ohm
spec_tip_antena Tip antenă Magnetică
spec_* Orice altă specificație (înlocuiește * cu numele) valoare

⚠️ Note Importante

  • Prețurile trebuie să fie în BANI (nu lei) - ex: 459 lei = 45900
  • Encoding fișier: obligatoriu UTF-8 pentru diacritice românești
  • Separator: virgulă (,) - textele cu virgule trebuie între ghilimele duble "text, cu virgulă"
  • Imagini: trebuie să fie URL-uri publice accesibile (preferabil HTTPS)
  • SKU: trebuie să fie unic pentru fiecare produs
  • Categorii: dacă nu există, vor fi create automat la import
