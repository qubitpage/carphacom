E-Factura ANAF - Ghid Integrare

Ce este E-Factura?

E-Factura este sistemul național de facturare electronică gestionat de ANAF. Din 2024, este obligatoriu pentru tranzacțiile B2B în România.

Putem integra direct?

DA! ANAF oferă API public pentru:

  • • Upload XML facturi
  • • Verificare stare
  • • Download răspunsuri

Link-uri Oficiale

  • → Portal E-Factura ANAF
  • → Documentație Tehnică
  • → Mediu de Test

Flux Implementat în Sistem

1. Comandă Confirmată 2. Factură Generată Auto 3. Salvată în DB 4. Sync E-Factura (când activ)

Dacă E-Factura nu este configurat, facturile pot fi descărcate PDF și trimise manual la contabil.

Google Merchant Center - Ghid Pas cu Pas

1 Creare cont Google Merchant Center

Accesează și creează-ți contul gratuit:

Deschide Merchant Center

2 Activare Content API

Pentru sincronizare automată produse, activează API-ul:

  1. 1. Accesează Google Cloud Console - Content API
  2. 2. Click "Enable" pentru a activa API-ul
  3. 3. Creează Service Account pentru autentificare
→ Quickstart Guide Oficial

3 Configurare Feed Produse

Format XML/RSS pentru produse. Link-uri utile:

  • → Specificații Feed Produse
  • → Atribute Obligatorii
  • → API Reference Products

4 Conectare la Google Ads (opțional)

Pentru campanii Shopping Ads:

→ Google Shopping Ads

Notă: Pentru listare gratuită în tab-ul Shopping, nu ai nevoie de Google Ads. Doar Merchant Center + Feed valid.
